# PRD: 오늘의 할일 (Today's To-Do) 웹페이지

- 작성일: 2026-11-02
- 상태: 설계 (구현 전)

---

## 1. 개요

### 1.1 목적
사용자가 **오늘 해야 할 일**을 빠르게 적고, 완료 여부를 체크하며, 하루의 진행 상황을 한눈에 확인할 수 있는 가벼운 웹페이지를 만든다.

### 1.2 배경 / 문제
- 일반적인 할일 앱은 기능이 많아 "오늘 할 일"에만 집중하기 어렵다.
- 설치나 로그인 없이 브라우저만 열면 바로 쓸 수 있는 도구가 필요하다.

### 1.3 목표
| 구분 | 내용 |
|---|---|
| 핵심 목표 | 오늘의 할일을 추가·완료·삭제하고, 새로고침해도 데이터가 유지된다 |
| 사용성 목표 | 페이지 진입 후 3초 안에 첫 할일을 추가할 수 있다 |
| 기술 목표 | 별도 서버·빌드 없이 정적 파일(HTML/CSS/JS)만으로 동작한다 |

### 1.4 비목표 (이번 범위에서 제외)
- 회원가입 / 로그인 / 여러 기기 간 동기화
- 서버 · 데이터베이스
- 반복 일정, 알림(푸시), 캘린더 연동
- 협업(공유) 기능

---

## 2. 대상 사용자

- **주 사용자**: 하루 단위로 할 일을 정리하고 싶은 개인 (학생, 직장인)
- **사용 환경**: 데스크톱 브라우저(Chrome, Edge, Safari 최신 버전) 및 모바일 브라우저

### 사용자 스토리
1. 나는 아침에 오늘 할 일을 빠르게 적고 싶다.
2. 나는 일을 끝낼 때마다 체크해서 성취감을 느끼고 싶다.
3. 나는 오늘 몇 개를 끝냈는지 진행률로 보고 싶다.
4. 나는 브라우저를 닫았다 열어도 목록이 그대로 남아 있길 원한다.
5. 나는 잘못 적은 할일을 수정하거나 지우고 싶다.

## 3. 기능 요구사항

우선순위: **P0** = 필수(MVP), **P1** = 있으면 좋음, **P2** = 추후 고려

### 3.1 할일 관리
| ID | 기능 | 설명 | 우선순위 |
|---|---|---|---|
| F-01 | 할일 추가 | 입력창에 텍스트 입력 후 Enter 또는 "추가" 버튼으로 추가. 공백만 있는 입력은 무시 | P0 |
| F-02 | 완료 토글 | 체크박스 클릭 시 완료/미완료 전환. 완료 항목은 취소선 + 흐린 색 | P0 |
| F-03 | 할일 삭제 | 각 항목의 삭제 버튼으로 제거 | P0 |
| F-04 | 할일 수정 | 항목 텍스트를 더블클릭(모바일: 수정 버튼)하면 인라인 편집. Enter 저장, Esc 취소 | P1 |
| F-05 | 완료 항목 일괄 삭제 | "완료된 항목 지우기" 버튼 | P1 |
| F-06 | 순서 변경 | 드래그 앤 드롭으로 순서 변경 | P2 |
| F-07 | 우선순위 표시 | 항목별 중요 표시(★) 토글, 중요 항목 상단 정렬 | P2 |

### 3.2 보기 / 필터
| ID | 기능 | 설명 | 우선순위 |
|---|---|---|---|
| F-10 | 필터 | 전체 / 진행 중 / 완료 탭 | P1 |

| ID | 기능 | 설명 | 우선순위 |
|---|---|---|---|

| F-21 | 진행률 | "3 / 5 완료" 텍스트 + 진행 바(%) | P0 |

| 항목 | 요구사항 |

### 5.2 화면 상태
| 상태 | 표시 |
|---|---|
| 빈 목록 | 일러스트/아이콘 + "오늘 할 일을 추가해 보세요" |
| 일부 완료 | 진행 바 + 남은 개수 |
| 전부 완료 | "오늘 할 일을 모두 끝냈어요! 🎉" |
| 저장 불가 | 상단 노란 배너 "이 브라우저에서는 데이터가 저장되지 않아요" |

- 색상: CSS 변수로 정의 (`--bg`, `--text`, `--primary`, `--done`) → 다크 모드 대응 용이
- 인터랙션: 항목 추가/삭제 시 짧은 페이드 애니메이션(150ms)

## 6. 데이터 설계

### 6.1 Todo 객체
```json
{
  "id": "1730505600000-a1b2",
  "text": "운동 30분",
  "done": false,
  "important": false,
  "createdAt": "2026-11-02T08:00:00.000Z",
  "completedAt": null
}
```

### 6.2 localStorage 구조
| 키 | 값 | 설명 |
|---|---|---|
| `todo:v1:2026-11-02` | `Todo[]` (JSON) | 날짜별 할일 목록 |
| `todo:v1:settings` | `{ "theme": "system", "filter": "all" }` | 사용자 설정 |

- 날짜 키는 **사용자 로컬 시간 기준** `YYYY-MM-DD`
- `v1` 버전 접두어로 향후 스키마 변경 시 마이그레이션 가능

## 7. 기술 설계

### 7.1 파일 구조 (예정)
```
todolist/
├── prd.md          ← 본 문서
├── index.html      ← 마크업
├── style.css       ← 스타일 (CSS 변수, 반응형, 다크 모드)
└── app.js          ← 상태 관리, 렌더링, 저장
```

### 7.2 app.js 모듈 구성
| 모듈 | 책임 |
|---|---|
| `storage` | `load(dateKey)`, `save(dateKey, todos)` — try/catch로 localStorage 감싸기 |
| `state` | 현재 todos 배열, filter 값 보관. 변경 함수(`add`, `toggle`, `remove`, `edit`, `clearDone`) |
| `render` | state → DOM 반영 (목록, 진행률, 빈 상태, 필터 탭 활성화) |
| `events` | 입력/클릭/키보드 이벤트 바인딩 (목록은 이벤트 위임 사용) |
| `date` | 오늘 날짜 키 생성, 화면 표시용 포맷(`Intl.DateTimeFormat('ko-KR')`) |

### 7.3 데이터 흐름
```
사용자 입력 → events → state 변경 함수 → storage.save() → render()
```
- 단방향 흐름: 모든 변경은 state 함수를 거친 뒤 저장 → 전체 렌더

## 8. 수용 기준 (Acceptance Criteria)

- [ ] 할일을 입력하고 Enter를 누르면 목록 맨 아래에 추가되고 입력창이 비워진다
- [ ] 빈 문자열/공백만 입력하면 추가되지 않는다
- [ ] 체크박스를 누르면 취소선이 생기고 진행률이 즉시 갱신된다
- [ ] 삭제 버튼을 누르면 항목이 사라지고 진행률이 갱신된다
- [ ] 새로고침 후에도 목록과 완료 상태가 그대로 유지된다
- [ ] 할일이 0개일 때 빈 상태 안내가 보인다
- [ ] 상단에 오늘 날짜가 한국어 형식으로 표시된다
- [ ] 모바일(360px)에서 가로 스크롤 없이 모든 기능을 쓸 수 있다
- [ ] `<script>` 같은 문자열을 입력해도 텍스트로만 표시된다
